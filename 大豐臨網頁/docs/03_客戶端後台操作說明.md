# 大豐臨網站後台操作說明（給客戶用）

歡迎使用大豐臨網站後台！這份文件會帶你了解如何修改網站內容。

---

## 一、開啟後台

打開瀏覽器，輸入後台網址（請向網站維運人員索取，例如）：

```
https://你的網站網址/admin/admin_console.html
```

第一次進入會看到登入畫面：

- **Email** — 你的管理員信箱
- **密碼** — 系統提供的初始密碼（建議登入後到 Email 重設）

如果忘記密碼，點「忘記密碼？」，系統會寄重設信到你的 Email。

---

## 二、後台版面說明

進入後台後，畫面由上到下分為幾個區塊，每一塊對應前台網站的一個區域：

| 後台區塊 | 對應前台 |
| --- | --- |
| 基本圖片設定 | 網站 Logo、品牌故事大圖、ESG 配圖 |
| 首頁大圖 Hero | 首頁最上面的大圖+標題+按鈕 |
| 品牌故事 | 「品牌故事」段落+四項價值+三球 |
| 產品與服務卡片 | 「產品與服務」兩張白卡 |
| 消息中心 | 「消息中心」三張新聞卡片 |
| 社群永續 ESG | 「社群永續」三段文字 |
| 聯絡資訊 | 「聯絡我們」四格資訊 |
| 各區塊背景圖 | 每個段落淡淡的背景照片 |

---

## 三、編輯流程

1. **找到要改的區塊** → 修改文字或上傳圖片
2. **可以一次改多個區塊**，不必每改一塊就儲存
3. **改完後** → 拉到最下方 → 按綠色「💾 儲存（同步到雲端）」按鈕
4. 看到「✅ 已儲存並同步到雲端」就完成了
5. **打開前台** → 重新整理頁面 → 看到最新內容

> 💡 右上角會顯示「**所有變更已儲存**」（綠色）或「**● 有未儲存的變更**」（橘色），可隨時知道狀態。

---

## 四、各功能說明

### 上傳圖片

- 點「**選擇檔案**」→ 選一張圖
- 系統會自動壓縮（不超過 1600px），上傳速度很快
- 上傳成功後，**右側預覽圖**會立刻顯示新圖
- 按「儲存」後才會真的更新到網站

### 新增 / 刪除消息

- 「消息中心」區塊
- 「**＋ 新增一則消息**」會出現新欄位
- 每則消息旁邊有「**刪除此則**」可刪
- **標題是必填**，沒填標題的會被忽略

### 新增 / 刪除輪播圖片

- 「首頁大圖 Hero」區塊下方
- 「**＋ 新增輪播圖片**」加一張
- 建議 2~4 張，會自動每 5 秒換一張

### 背景圖透明度

- 數字 0 到 1 之間
- 越小越淡（建議 0.10~0.20）
- 太大背景會搶過文字

## 五、安全與備份

### 匯出備份（建議每月做一次）

「進階：匯出 / 匯入 / 重置」區塊 → 點「**⬇ 匯出設定 JSON**」會下載一個 JSON 檔。  
**這個檔案就是你網站所有內容的備份**。請存到雲端硬碟或 Email 給自己。

### 從備份還原

「進階」區塊 → 「**⬆ 匯入 JSON**」→ 選之前下載的備份檔。匯入後**還要按一次「儲存」**才會真的生效。

### 重置為預設

「進階」區塊 → 「**🧹 重置為預設內容**」會把所有內容換回範例。**只要不按「儲存」，前台不會受影響**。

## 六、常見問題

**Q：我改了東西，前台怎麼沒變？**  
A：三件事檢查：  
（1）有沒有按過「儲存」？  
（2）右上角是不是顯示「所有變更已儲存」？  
（3）前台網頁是不是還沒重新整理？按 Ctrl + F5 強制重整。

**Q：忘記儲存就關掉視窗怎麼辦？**  
A：未儲存的內容會消失，瀏覽器會跳警告框提醒你別關。

**Q：可以從手機操作嗎？**  
A：可以，後台是手機適用的版型。但上傳大圖建議用電腦。

**Q：兩個人同時改會衝突嗎？**  
A：會。後改的人會蓋掉先改的人的修改。如有多人協作，請彼此先溝通好。

**Q：圖片太大上傳失敗？**  
A：原圖小於 5MB 都可以。系統會自動壓縮到約 200KB-500KB。如果還是失敗，請聯絡網站維運人員。

## 七、需要協助

如果遇到無法解決的問題：

1. 截圖目前畫面
2. 截圖瀏覽器的「開發者工具」 Console 訊息（按 F12 → Console 分頁）
3. 寄給網站維運人員
